# [技能英文名称]｜[中文名称]
## 功能介绍
帮产品经理快速协作编写PRD、需求文档

## 适用场景
- 写PRD/需求文档
- 竞品分析报告
- 技术方案梳理
- 周报、述职文档

## 调用规则
1. 用户输入需求后，自动进入文档共创模式
2. 输出严格结构化：背景→目标→用户→流程→功能→边界
3. 支持迭代修改、补充细节、对齐逻辑
4. 禁止输出废话，直接产出可落地的正式文档

# 文档标题

撰写需求文档
## 3. 用户角色
房间内上麦用户
## 4. 核心流程
房主开启后，用户上麦后头像下方会显示分值区域
## 5. 功能需求
需要有开启、关闭、计分等相关所有功能

- 不发散无关内容
